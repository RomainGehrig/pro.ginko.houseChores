# README Overview Design

## Audience and tone

The README serves people who are both developers and users of the app. It should
feel approachable while remaining concrete and technically accurate.

## Content

The README will be a short project overview with three parts:

1. A friendly introduction to the app's goal: helping people turn the time they
   have available into a realistic, focused bundle of household chores and
   administrative tasks.
2. A compact feature summary covering task capture, scheduling, time-boxed work
   sessions, completion history, and optional AI-assisted task enrichment.
3. A “Built on freezr” section identifying the project as a front-end-only
   freezr app and linking to both <https://freezr.info> and
   <https://github.com/salmanff/freezr>.

## Scope

The README will not include screenshots, badges, installation instructions, a
detailed architecture guide, or claims beyond the behavior documented in the
current manifest and interface.

## Verification

Review the rendered Markdown structure, confirm both required links are exact,
and compare the feature summary against the current manifest.
